# Changelog

## 3.1.0
- Added Russian (Русский) interface language.

## 3.0.0
- Single small `.exe` (C#, WinForms) — nothing to install.
- Interactive world map: click servers, drag, zoom, line from your location to the chosen servers.
- Automatic location detection on start (right-click the map to set it by hand).
- Rules update automatically when Valve changes the relay IPs.
- Auto "best ping", continent shortcuts, English / Español / Português.
- Portable data folder, per-PC state, app icon.
